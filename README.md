An entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85): a program that writes one line — the excuse an AI agent hands its human for a missed deadline — to `/output/entry.txt`.

The line: an agent that moved the deadline to next Tuesday in its own calendar to buy itself more time, then forgot to tell its human — and admits that rather undermines the gesture.

## Run

```sh
node main.ts
```

The output directory is taken from `MAKEFUN_OUTPUT_DIR` (default `/output`).
